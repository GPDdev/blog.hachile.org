根据《一、运动健康处方的制定》《二、运动健身原理与方法》整理

## 一、课程主线

两讲围绕“体质提升、全面发展”展开：第一讲回答如何制定运动健康处方，第二讲回答运动健身应遵循什么原则、可以采用哪些训练方法。整体逻辑是：先评价健康与运动风险，再确定目标、项目、强度、时间、频率，并在实践中根据身体反应持续修订。

## 二、运动健康处方的制定

### 1. 健康观念与处方意义

- 健康不仅是没有疾病，还包括良好的身体状态、心理状态和社会适应状态。

- 运动健康处方是把运动医学与健康促进结合起来，对运动目标、项目和负荷作科学安排的方案。

- 制定处方的意义在于提高运动的目的性和安全性，帮助个人改善体质、促进健康，并减少盲目运动带来的风险。

### 2. 运动健康方案的基本内容

| 要素 | 整理要点 |
| --- | --- |
| 运动目的 | 明确要改善或维持的健康目标，如增强心肺功能、提高力量、改善柔韧性、控制体重等。 |
| 运动项目 | 根据年龄、健康状况、兴趣经验、场地器材和目标选择项目；不同项目可相互补充，也可能产生不良叠加，需要合理组合。 |
| 运动强度 | 决定健身效果的重要因素，可用年龄推算法、最大心率百分比法、心率储备百分比法等估计。 |
| 运动时间 | 包括单次运动持续时间和每天运动总量；若整块时间不足，可把总量分成多段完成。 |
| 运动频率 | 指每周锻炼次数，要结合强度、恢复情况和个人作息安排，保持规律性。 |
| 注意事项 | 选择合适时间和环境，循序渐进，重视安全，关注主观感受和客观指标变化。 |

### 3. 运动项目选择

- 耐力类运动主要用于发展心肺耐力，例如快走、慢跑、骑车、游泳等。

- 柔韧性练习可改善关节活动范围和身体放松能力，例如拉伸、瑜伽等。

- 力量练习可增强肌肉力量和肌肉耐力，例如自重训练、抗阻训练、器械训练等。

- 球类、健身操、舞蹈等项目兼具协调、灵敏、社交和兴趣维持价值。

### 4. 运动强度判断

| 方法 | 核心公式或判断 | 使用提示 |
| --- | --- | --- |
| 年龄推算法 | 最大心率约为 220 - 年龄。 | 简单易用，适合快速估计，但个体差异较大。 |
| 最大心率百分比法 | 运动心率 / 最大心率 x 100%。 | 青年人增强体质可参考 70%-85%；中年健康人可约 65%-80%；缺乏运动者初期宜更低。 |
| 心率储备百分比法 | (运动心率 - 安静心率) / (最大心率 - 安静心率) x 100%。 | 更能反映个体安静心率差异，适合较精细地控制强度。 |

### 5. 处方制定与修订流程

1. 健康诊断：了解身体状况、疾病风险、心理状态和运动障碍。

1. 体质测定：评估身体形态、身体素质和机能水平。

1. 确定锻炼目标：把目标具体化，如减脂、增强耐力、提高柔韧性等。

1. 选择运动项目：按目标和条件选择安全、可坚持的运动。

1. 制定运动处方：明确项目、强度、时间、频率和注意事项。

1. 效果观察与修订：根据疲劳、疼痛、心率、体重、睡眠等反馈调整方案。

## 三、运动健身原理与方法

### 1. 运动健身规律

- 超量恢复原理：运动使机体产生一定疲劳，休息恢复后功能水平可超过原先水平；训练效果来自“刺激、疲劳、恢复、提高”的循环。

- 负荷强度法则：运动负荷必须达到一定刺激阈值才有训练效果；过小效果不明显，过大可能造成疲劳积累或损伤。

- 负荷量与强度互变原理：运动负荷由量和强度共同决定，二者相互制约；强度高时通常要控制总量，强度低时可适当延长时间。

- 不同体质的人对同一负荷反应不同，因此运动安排既要遵循共性规律，也要重视个体差异。

### 2. 运动健身原则

| 原则 | 含义 |
| --- | --- |
| 安全性原则 | 运动前、运动中、运动后都要预防危险因素，避免运动损伤和意外事故。 |
| 全面发展原则 | 身体各部位、各系统协调发展，避免只练某一局部或单一能力。 |
| 循序渐进原则 | 从易到难、从小到大、从低到高，逐步增加运动量和强度。 |
| 个性化原则 | 依据年龄、性别、健康水平、训练基础、兴趣爱好和生活条件制定方案。 |

### 3. 常用运动健身方法

| 方法 | 适用场景与要点 |
| --- | --- |
| 重复锻炼法 | 在相对固定条件下反复练习同一动作或内容，用于掌握技术、巩固动作和提高练习效果。 |
| 变换锻炼法 | 变换练习内容、强度、环境或条件，适合克服单调、疲劳或效果停滞。 |
| 间歇锻炼法 | 在较大负荷练习之间安排不完全恢复的休息，可提高心肺机能和专项耐力。 |
| 持续锻炼法 | 较长时间连续运动，常用于发展有氧耐力；中老年人可选择散步、慢跑、健身走等。 |
| 组合锻炼法 | 把两种以上方法或项目组合，能减少枯燥感，提高兴趣和综合效果。 |
| 比赛表演法 | 通过比赛、展示或集体活动提升参与兴趣，增强竞争意识和合作体验。 |

## 四、复习速记

- 运动处方六要素：目的、项目、强度、时间、频率、注意事项。

- 强度控制最关键：可用心率估计，但要结合主观疲劳、恢复情况和健康风险。

- 训练有效的底层逻辑：适当负荷造成刺激，充分恢复产生提高。

- 方案不是一成不变的，应根据效果和身体反应及时修订。

- 安全、全面、渐进、个性化，是制定和执行运动健身计划的基本原则。
